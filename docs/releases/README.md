## Tags without a GitHub Release

`custom-v0.1.0-rc2` and `custom-v0.1.0-rc4` are historical candidate source tags.
They are not supported current downloads. `archive/rtc-persistence-prototype`
and `archive/kh-save-select-investigation-2026-09-05` preserve investigation
history; neither is a release. These refs are retained so old links and source
identities remain recoverable. No existing tag is moved, renamed or reused.

## Branch policy

`develop` is the default integration branch. Create temporary topic branches for
new work and remove them after review/merge. Release tags preserve exact published
source, so completed release branches need not remain active. Superseded PR #5/#6
are closed historical attempts, not pending changes to merge. See the
[repository maintenance record](../repository-maintenance-2026-10-02.md).
